# 未央音频播放器（本地音频 APK）

一个**完全离线、不联网**的 Android 本地音频播放器。音频放在手机存储的一个文件夹里
（根目录下**任意数量**的子目录，每个子目录里放若干音频文件；你现在是 26 个，多少都行），
App 通过系统"文件夹选择"授权后读取并播放。

## 功能
- 📁 按 26 个目录分组浏览、点文件名即播
- ▶️ 基础播放：播放 / 暂停、上一首 / 下一首、进度条拖动
- 🔒 后台 + 锁屏播放（通知栏与锁屏可控制）
- 💾 记住播放进度：关掉再打开，自动回到上次听到的文件与位置
- 🐢 变速播放：0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×（"牛听听"式磨耳朵）
- 🔁 循环模式：顺序 → 单曲循环 → 列表循环 → 随机
- ⏱ 睡眠定时：15 / 30 / 45 / 60 / 90 分钟，到点自动暂停
- ★ 收藏：当前音频点 ☆ 变 ★，右上角"收藏"可回顾

## 一、用 Android Studio 编译出 APK
> 本机没有 Android 编译环境，所以由你在自己电脑上编译（一次性，约 1GB 下载）。

1. 在电脑上安装 **Android Studio**（官网：developer.android.com/studio，点 "Download"）。
2. 安装时一路默认即可；首次启动会下载 SDK（约几百 MB~1GB，需联网）。
3. 打开 Android Studio → `File` → `Open` → 选择本项目的 `AudioPlayerApp` 文件夹。
4. 等待右下角 "Gradle sync" 完成（首次会自动下载 Gradle 8.9）。
5. 连上手机（打开"开发者选项 → USB 调试"），或选一个模拟器：
   - 直接装到手机/模拟器：`Run` → `Run 'app'`（或按 Shift+F10）。
   - 只生成 APK 文件：`Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`。
     完成后点右下角弹窗的 **locate**，得到
     `app/build/outputs/apk/debug/app-debug.apk`。
6. 把 `app-debug.apk` 拷到手机安装即可（首次安装需在手机上允许"未知来源"）。

## 二、手机上使用
1. 第一次打开 App，会弹出"选择文件夹"——**选中存放 26 个目录的那个根文件夹**，
   并勾选 **"永久访问此文件夹 / 允许访问"**（这样以后不用重复选）。
2. 顶部出现 26 个目录标签，点一个进入；下面是该目录的音频列表，点任意一条开始播放。
3. 底部控制条：
   - `⏮ ⏯ ⏭` 上一首 / 播放暂停 / 下一首
   - 进度条可拖动；`0:00` 左侧是当前时间，右侧是总时长
   - `1×` 变速（每点一次切换一档）
   - `🔁` 循环模式（顺序→单曲→列表→随机，图标会变）
   - `⏱` 睡眠定时
   - `☆` 收藏当前音频（变 ★）；右上角"收藏"菜单回顾
4. 锁屏或下拉通知栏会出现播放控制，可后台播放。
5. 退出 App 再进，会自动恢复到上次听的文件和位置。

## 三、文件夹结构要求
```
你的根文件夹/
├── 目录1/
│   ├── 音频A.mp3
│   └── 音频B.mp3
├── 目录2/
│   └── ...
├── ...
└── 目录N/        ← N 是任意数量，不限于 26
    └── ...
```
- 支持格式：mp3 / m4a / aac / wav / flac / ogg / wma / opus / amr
- 音频文件**不打包进 APK**，放在手机存储即可（总大小几个 GB 也没问题）。
- 每个子目录下的文件按文件名排序播放（建议文件名带序号，如 `01_xxx.mp3`）。
- App 会读取根目录下**所有**子文件夹，数量多少都自动识别。

## 四、常见问题
- **选错文件夹 / 想换文件夹**：在手机"设置 → 应用 → 未央音频 → 清除数据"，
  重新打开会再次让你选文件夹。
- **通知/锁屏不显示控制**：Android 13+ 首次会请求"通知"权限，请允许；
  或在系统设置里给"未央音频"开启通知。
- **某目录没出现在列表**：确认它是根文件夹下的**子目录**，且里面至少有
  一个上述格式的音频文件。

## 技术说明（给好奇的你）
- 语言：Kotlin；播放内核：AndroidX Media3（ExoPlayer + MediaSession）
- 后台/锁屏：通过 `MediaSessionService` 自动生成媒体通知实现
- 文件访问：使用 SAF（存储访问框架），只读取你授权的文件夹，不上传任何数据
- 最低支持 Android 7.0（API 24），目标 Android 14（API 34）
